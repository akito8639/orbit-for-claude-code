Design proposal · macOS 27 · WidgetKit

Orbit for Claude Code — デザイン 3 案

Claude Code の使用量をペース目標マーカー付きで表示する macOS ウィジェットです。3 案すべて実装済みで、設定の「デザイン」タブから切り替えられます。現在は Usage のほかに Sessions / Cowork / Claude status / Today の 4 ウィジェットが加わり、5 種類すべてが同じデザイン設定で描かれます。画像は実際のアプリがレンダリングした Small (164×164) / Medium (344×164) / Large (344×344) で、macOS 27 の実測サイズです。

推奨A · Glass OrbitLiquid Glass

二重リングで「今の 5 時間」と「今週」を一目で

外リング＝週、内リング＝5 時間。リング上の白い目盛りが「今この時点で使っていて良い量（ペース目標）」で、色付きの弧がそれを越えると橙→赤に変わります。中央には最も逼迫している枠の％。

macOS 27 らしさ
  • ウィジェットの「クリア / 着色」表示では widgetAccentable でリングとバーだけをアクセント化し、システムの Liquid Glass 越しに浮かせます
  • メニューバーのパネルは glassEffect + GlassEffectContainer、ボタンは .glass スタイル
  • 背景は状態色（緑/橙/赤）とテラコッタの放射グラデーションで、悪化すると空気が変わる
向いている人
  • デスクトップにウィジェットを常設し、遠目でペースを把握したい
  • 数字より「形」で読みたい
B · Pace Bars参考画像準拠

参考画像の構成を Claude Code 専用に再構成

「WORST — CLAUDE WEEK」の見出し、ドーナツ、プラン バッジ（MAX 20x）、カプセルバー＋ペース目印、％、リセット時刻。参考画像で Codex に使っていた行を、Opus / Sonnet 別枠や追加クレジット枠（API が返した時だけ）に振り替えています。

macOS 27 らしさ
  • 参考画像と同じ紫系グラデーションですが、着色表示ではシステム色に自動で馴染みます
  • Large ではステータス / 起動中セッション / 今日のトークン量を下段に展開
向いている人
  • 参考画像の見た目が気に入っている
  • 行を増やして複数枠を並べたい
C · ConsoleClaude Code の空気感

❯ claude /usage の出力をそのまま置いたような佇まい

モノスペース、プロンプト記号、点滅カーソル。緑 / 琥珀 / 赤の 3 色だけで状態を伝えます。ターミナルと並べても違和感がなく、Claude Code 専用であることが最も強く出る案です。

macOS 27 らしさ
  • ほぼ黒の背景は着色表示にすると素通しのガラス板になり、ネオン風の文字だけが残ります
向いている人
  • 常にターミナルを開いている
  • 装飾より情報密度

ペース判定の仕組み（3 案共通）

各枠のリセット時刻から枠の開始時刻を逆算し、経過割合を「目標ペース」として目盛りに描きます。使用率が目標を +10pt 以上上回ると above target、+25pt 以上で well above target、それ以外は on track。見出しには最も悪い枠が出ます。

推奨

A · Glass Orbit を既定に、B を「参考画像そのまま派」向け、C をターミナル常駐派向けの選択肢として残すのが良いと考えます。A は macOS 26/27 の着色・クリア表示で最も映え、Small サイズでも意味を失いません。B は Medium 以上でこそ活きます。

いずれも同じデータ層・同じ設定を使うため、切り替えはメニューバーのセグメント、または設定 →「デザイン」から即時に反映されます。

導入手順

brew tap akito8639/tap && brew trust akito8639/tap
brew install --cask orbit-for-claude-code
# 1. メニューバーに ✱ 85% のような表示が出る（初回は設定が自動で開く）
# 2. デスクトップを右クリック →「ウィジェットを編集」→「Orbit」で検索 → 5 種類から配置
# 3. トークンが期限切れなら、ターミナルで `claude` を起動して /login
